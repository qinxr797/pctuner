# 电脑调优助手 v6.1 交互动效

老板觉得 v6.0 的界面「点按钮没有动画」「动效不够丰富」「不够优雅」，想让鼠标交互更有意思，点了要有反馈。他在试玩台上挑好了候选效果，现在要你把动效做进 D:\ClaudeWork\pctuner（PowerShell 5.1 + WPF + MaterialDesignInXamlToolkit 5.3.2，当前 v6.0）。

**老板的要求原话：十个不一定非要全部做进去，但是一定要高级、和谐。**
所以你不是照单全收的执行者。要先用 skill 判断每个效果该不该做、做在哪、做到什么程度，宁可少做，也不做出廉价感。

## 老板的选择

- **手感：A3 弹簧。** 松手时稍微弹过头再回来，有肉感，像 iPhone
- **候选效果（10 个）：**
  - B3 加载变成功：按钮缩成转圈，干完变成绿色对勾，再复原
  - C2 光斑跟随：卡片里一团淡光跟着鼠标走
  - C4 选中描边 + 对勾：点击后强调色描边，右上角弹出对勾
  - D1 弹簧开关：圆点滑动带回弹，按住时拉长
  - D2 画勾勾选框：方框先弹一下，对勾一笔画出
  - D4 数字滚动 + 圆环同步画满
  - D5 列表依次进场
  - D6 提示条滑入：右下角滑入，带倒计时细线，时间到自己滑走
  - D7 图标微动：刷新转半圈、垃圾桶晃一下、闪电跳一下
  - D8 进度条流动：分段平滑前进，带流动斜纹，跑完变绿
- **新增：区块切换过场。** 老板点名要：侧边栏切换功能页时要有过场动画。页面内部如果有子区块或分段切换，也一起纳入
- **系统关了动画时：照播。** 老板的电脑关着 Windows「显示动画」，他拍板软件无视这个系统设置，动效照常播放。想关只认软件「个性化」页里自己的动画开关。现在 `$Script:SystemAnimOff` 那套「减弱去位移」的逻辑要去掉，Modules\Motion.ps1 和 PCTuner.ps1 里相关的注释同步改掉

## 参考实现

`docs\动效试玩台.html` 是老板亲手试过的网页版，里面的曲线、时长、缩放比例都是他看过、点过的，当作手感基准：
- A3 弹簧：按下 90ms 缩到 0.9（ease-out），松手 620ms 回弹。回弹曲线是 CSS `linear()` 采样的弹簧，超调约 16%。实际按钮上用 0.95～0.97 这种更克制的缩放，自己判断
- 其余每个效果的 CSS 和 JS 都在文件里，直接读来对照

## 必须用 skill，按这个顺序

1. **improve-animations**：先把现有动效全审一遍（Modules\Motion.ps1、XAML 里的 TransitioningContent、RippleAssist、各种 New-* 构建函数），列出现在哪里廉价、哪里缺失、哪里冲突
2. **emil-design-eng** 和 **apple-design**：定整套动效语言。弹簧怎么调、哪些属性该动、时长梯度多少、怎样做到可打断、什么地方必须克制
3. 逐个效果做判断，输出「做 / 不做 / 改着做」，每条附一句理由。判断标准就是老板说的「高级、和谐」
4. **animate**：对决定要做的效果逐个实现

## 和谐的底线（skill 判断之外，这几条先定死）

- **一套动效语言。** 位移和缩放统一用一条弹簧；透明度和颜色用 ease-out，不弹。时长只允许几个档位，写进 design.md 的动效一节，代码里不许出现规范外的数字
- **同一时刻只有一个主角在动。** 过场、列表依次进场、数字滚动这三个会在「切到一个新页面」的同一瞬间撞在一起，必须编排好，不许叠成一团乱动。可以是过场本身就是依次进场，也可以按顺序接力，让 skill 决定
- **全部可打断。** 快速连点侧边栏、连点开关、清理没做完就切页，都不许卡顿、排队或者停在半截
- **克制放置。** C2 光斑这类装饰性效果只放在少数主角卡片上，不许满屏都有。D7 图标微动只放在侧边栏和工具按钮上。一个效果放在哪、放几处，要在报告里写清楚
- 语义色不跟着动效变：高危永远是红色，成功用 ok 绿

## WPF 上的技术坑（先看）

- **KeySpline 的控制点被限制在 0～1**，做不出 CSS `cubic-bezier(.34,1.56,…)` 那种超调，所以 Motion.ps1 现在那套 KeySpline 做不了弹簧。可选做法有三种：
  - 按阻尼弹簧公式预先采样，生成 DoubleAnimationUsingKeyFrames（纯 PowerShell，结果可复现）
  - 用 Add-Type 编一个继承 EasingFunctionBase 的 C# 缓动类
  - 用 BackEase / ElasticEase 凑
  选哪种、为什么，写进报告。要求手感接近试玩台的 A3
- MDIX 5.3 的 TransitioningContent 设 RunHint 不会重播动画。现在的切页是靠反射调 `RunOpeningEffects`（`Invoke-PageTransition`）。过场如果要重做，可以不再依赖它
- TabControl 只给当前页建可视树，挂事件要用 RegisterClassHandler 做类级注册
- **PrintWindow 截不到 RenderTransform。** 验动效要么在程序里读属性，要么用 CopyFromScreen 按 16～33ms 连拍几帧，确认中间帧真的在动
- 含中文的 .ps1 必须是 UTF-8 with BOM，而且只有 powershell.exe 5.1 下才炸，PS7 验不出来
- 往资源字典塞画笔要显式转 `[Brush]`；设 Source 或 BaseTheme 要用 `set_Source()` / `set_BaseTheme()`
- 性能：光斑跟随、进度条斜纹这类持续动画，用 CompositionTarget.Rendering 或 DispatcherTimer 时注意 CPU 占用。页面切走就要停掉，不许后台空转

## 不许动的

- 功能和逻辑不动，只加动效
- design.md 里原有的色板、字号、间距不动，只新增和改写动效一节
- 硬约束照旧：Backup 原值还原、语义色不换肤、卸载黑名单、激进项默认不勾、读不到显示「—」、超频页不改设置

## 验收

- 每个做了的效果都要真启动 powershell.exe 5.1 跑一遍，连拍帧确认在动，并且手动快速连点测过可打断
- 三个自检全过：`powershell.exe -File PCTuner.ps1 -SelfTest`、`dev\对比度自检.ps1`、`py dev\漏网色号自检.py`。自检里加一条硬检查：弹簧缓动和过场动画确实挂上了
- 版本号升到 **v6.1**，重新打包到桌面（用 dev\打包.ps1，Fonts 和 Lib 要带上）
- 一个效果一个 commit
